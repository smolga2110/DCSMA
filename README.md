# Разработка мобильных приложений

Выполнены 25 практических работ модулей 4–6.

## Как открыть

Требуется JDK 21; Android SDK 35 — для мобильных проектов. На Windows в путях с кириллицей для командной сборки и тестов используйте `verify.ps1` из папки задания.
