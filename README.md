# Разработка мобильных приложений

Выполнены 25 практических работ модулей 4–6. Каждое задание — самостоятельный проект с исходным кодом, Gradle Wrapper и инструкцией запуска. Для 21 Android-приложения приложены APK и собственные скриншоты. Три итоговых отчёта Word расположены в папке `Отчеты`, без титульных листов, с обновлёнными оглавлениями.

## Как открыть

Выберите задание в таблице и откройте его папку в Android Studio (Android) либо IntelliJ IDEA (консоль/сервер). Следуйте README конкретного задания. Требуется JDK 21; Android SDK 35 — для мобильных проектов. На Windows в путях с кириллицей для командной сборки и тестов используйте `verify.ps1` из папки задания.

## Проверки и границы

Все проекты собраны. Основные экранные сценарии проверены на Android 15 API 35. Оба сервера прошли по 14 HTTP-проверок; серверные модульные тесты и 4 теста BLE-парсера пройдены. PostgreSQL подключён к Neon с TLS. Физический BLE-датчик не использовался, точность компаса на реальном устройстве не измерялась. Облачная загрузка, погода и курс валют имитируются там, где это предусмотрено учебной реализацией.

## Подготовка к Git

Можно публиковать весь каталог либо каждую папку задания отдельно. `.gitignore` есть на обоих уровнях и исключает `.env`, настройки SDK, кэш сборки и APK. Локальный `.env` задания 5 модуля 6 хранит приватные настройки Neon; в репозиторий переносится только `.env.example`. Внешние сервисы и библиотеки могут меняться; версии зависимостей зафиксированы в проектах. Файлы отчётов и скриншотов входят в комплект; APK доступны локально и при необходимости могут быть загружены как release assets.
