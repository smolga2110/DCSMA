# Модуль 5. Практическая работа 3

Экспорт фотографии через MediaStore

## Цель

Дополнить фотогалерею копированием выбранной фотографии в общедоступную медиатеку Android.

## Реализация

Команда экспорта доступна в меню каждой фотографии и на экране просмотра. В MediaStore создаётся запись с MIME image/jpeg и каталогом Pictures/MyGallery. На Android 10 и выше используется IS_PENDING: объект становится доступен другим приложениям после завершения записи. При ошибке незавершённая запись удаляется. Для Android 8–9 предусмотрен запрос WRITE_EXTERNAL_STORAGE.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m5t03-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Проверены выбор команды экспорта и создание записи в системной медиатеке. После успешного копирования появляется Snackbar «Фото добавлено в галерею». Приватный оригинал сохраняется. Экспорт не выполняется путём прямой записи в общедоступный файловый путь.

Сделайте снимок, откройте его и выполните экспорт. Проверьте сообщение об успехе и появление изображения в системной галерее.

## Файлы

`app/src/main` — код, ресурсы и манифест; `apk` — проверенная отладочная сборка.

`screenshots` содержит снимки реально запущенного приложения, если у работы есть интерфейс; `verification` — протоколы при наличии. Групповой отчёт находится в общей папке `Отчеты`. Каждый проект имеет собственный Gradle Wrapper и может публиковаться отдельно.
