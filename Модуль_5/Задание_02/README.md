# Модуль 5. Практическая работа 2

Личная фотогалерея с камерой

## Цель

Создать приватную фотогалерею с получением полноразмерного изображения через системную камеру.

## Реализация

ActivityResultContracts.TakePicture получает URI от FileProvider. Файлы сохраняются в getExternalFilesDir(DIRECTORY_PICTURES) с именем IMG_yyyyMMdd_HHmmss.jpg. При совпадении имени добавляется суффикс. Отменённый снимок удаляется, чтобы пустой файл не попал в список. После возврата из камеры галерея обновляется и показывает фотографии в трёх колонках.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m5t02-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

На эмуляторе открыт интерфейс камеры, выполнен снимок виртуальной сцены и подтверждено сохранение. Фотография появилась в MyGallery. Изображения можно открыть отдельно. Разрешение CAMERA запрашивается во время выполнения; отсутствие камеры обрабатывается сообщением.

Разрешите камеру, сделайте и подтвердите снимок. Он должен появиться в сетке. В эмуляторе используется виртуальная сцена камеры.

## Файлы

`app/src/main` — код, ресурсы и манифест; `apk` — проверенная отладочная сборка.

`screenshots` содержит снимки реально запущенного приложения, если у работы есть интерфейс; `verification` — протоколы при наличии. Групповой отчёт находится в общей папке `Отчеты`. Каждый проект имеет собственный Gradle Wrapper и может публиковаться отдельно.
