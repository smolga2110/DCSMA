# Модуль 5. Практическая работа 4

Список задач с Room и DataStore

## Цель

Создать TodoList с постоянным хранением, однократным импортом JSON и сохранением настройки цвета выполненных задач.

## Реализация

Проект разделён на domain, data и presentation. Room хранит задачи и служебный признак импорта в таблице metadata. Проверка признака и вставка начальных задач выполняются в одной транзакции. Репозиторий предоставляет Flow списка; варианты использования отвечают за сохранение и удаление. DataStore хранит включение подсветки и выбранный цвет.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m5t04-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Начальные три задачи импортированы автоматически. Проверены добавление Verify Room и повторное открытие приложения. Переключатель «Цвет завершённых» изменяет оформление завершённых задач; палитра позволяет выбрать цвет. Импорт не привязан к пустоте таблицы, поэтому удаление всех задач не должно повторно создавать исходный набор.

После первого запуска импортируются три задачи. Создайте/измените/удалите задачу, отметьте выполнение, выберите подсветку. Повторный запуск сохраняет данные и не дублирует начальный импорт.

## Файлы

`app/src/main` — код, ресурсы и манифест; `apk` — проверенная отладочная сборка.

`screenshots` содержит снимки реально запущенного приложения, если у работы есть интерфейс; `verification` — протоколы при наличии. Групповой отчёт находится в общей папке `Отчеты`. Каждый проект имеет собственный Gradle Wrapper и может публиковаться отдельно.
