# Модуль 4. Практическая работа 9

Параллельный сбор прогноза погоды

## Цель

Сформировать прогноз трёх городов параллельно и объединить результаты отдельным Worker.

## Реализация

Для Москвы, Лондона и Нью-Йорка создаются независимые OneTimeWorkRequest. Их результаты объединяются ArrayCreatingInputMerger и передаются финальному Worker. Задачи используют foreground-режим WorkManager и обновляют уведомление. Финальный отчёт сохраняется в приватный файл, а интерфейс наблюдает за WorkInfo и отображает состояние каждого города.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t09-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Получены значения 21 °C, −2 °C и −7 °C. Средняя температура составила 4,0 °C: (21 − 2 − 7) / 3. На экране появились итоговый текст и состояние «Все данные получены». Погода является учебной имитацией, а не актуальной метеорологической информацией.

Температуры учебные и не являются актуальным прогнозом. Проверьте параллельные задачи и среднее значение 4 °C.

`screenshots` содержит снимки реально запущенного приложения, если у работы есть интерфейс; `verification` — протоколы при наличии. Групповой отчёт находится в общей папке `Отчеты`. Каждый проект имеет собственный Gradle Wrapper и может публиковаться отдельно.
