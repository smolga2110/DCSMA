# Модуль 4. Практическая работа 8

Последовательная обработка фотографии

## Цель

Построить цепочку WorkManager для сжатия фотографии, добавления подписи и имитации загрузки в облако.

## Реализация

Пользователь выбирает изображение системным диалогом. Первый Worker декодирует его с уменьшением разрешения и сохраняет JPEG с качеством 75. Второй Worker наносит водяной знак средствами Canvas. Третий имитирует передачу и возвращает демонстрационный URL. Путь к файлу передаётся через выходные Data; beginUniqueWork и then задают строгую последовательность.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t08-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Проверка выполнялась на снимке виртуальной камеры. Отображаются текущий этап и итоговый адрес. Повторный запуск исключён на время активной цепочки; предусмотрена отмена. Ошибки чтения и декодирования приводят к Result.failure, поэтому зависимые этапы не выполняются.

Выберите изображение. Проверьте последовательное сжатие, водяной знак и итог. Загрузка в облако имитируется, итоговый URL демонстрационный.

## Файлы

`app/src/main` — код, ресурсы и манифест; `apk` — проверенная отладочная сборка.

`screenshots` содержит снимки реально запущенного приложения, если у работы есть интерфейс; `verification` — протоколы при наличии. Групповой отчёт находится в общей папке `Отчеты`. Каждый проект имеет собственный Gradle Wrapper и может публиковаться отдельно.
