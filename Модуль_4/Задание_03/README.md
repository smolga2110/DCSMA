# Модуль 4. Практическая работа 3

Поиск репозиториев GitHub с задержкой ввода

## Цель

Создать экран поиска по локальному JSON-набору с debounce, индикатором загрузки и отменой предыдущего запроса.

## Реализация

В assets размещено 100 учебных записей с полями id, full_name, description, stargazers_count и language. Обработчик ввода отменяет прежний Job и создаёт новую корутину в rememberCoroutineScope. После паузы 500 мс файл читается через withContext(Dispatchers.IO); результат async передаётся в LazyColumn. Поиск учитывает имя, описание и язык.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t03-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

При запросе Kotlin отображена 61 подходящая запись. Проверены начальная загрузка и изменение запроса. На карточках представлены название, описание, число звёзд и язык. Набор является учебной локальной выборкой, поэтому поиск не зависит от доступности GitHub.

Набор репозиториев учебный, загружается из assets. Введите Kotlin, затем быстро измените запрос: предыдущий поиск должен отмениться.

## Файлы

`app/src/main` — код, ресурсы и манифест; `apk` — проверенная отладочная сборка.

`screenshots` содержит снимки реально запущенного приложения, если у работы есть интерфейс; `verification` — протоколы при наличии. Групповой отчёт находится в общей папке `Отчеты`. Каждый проект имеет собственный Gradle Wrapper и может публиковаться отдельно.
