# Модуль 4. Практическая работа 2

Поиск дубликатов JSON файлов с таймаутом

## Цель

Реализовать рекурсивный поиск одинаковых файлов по SHA-256 с ограничением продолжительности и корректной отменой операций.

## Реализация

Программа принимает каталог и таймаут в секундах. JSON-файлы перечисляются рекурсивно, а хеш вычисляется блоками по 64 КиБ в Dispatchers.IO. Semaphore ограничивает число одновременно открытых файлов четырьмя. Перед очередным чтением вызывается ensureActive. Результаты группируются по хешу; в вывод попадают только группы, содержащие несколько файлов.

## Запуск

Требования: JDK 21 и интернет для первой загрузки зависимостей. Запуск из **этой папки**: `./gradlew run` (Windows: `.\gradlew.bat run`). Сборка: `./gradlew build`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

На наборе samples обнаружена одна группа: a.json и nested/copy.json. Файл unique.json в неё не вошёл. При таймауте 0,000001 с получено сообщение «Поиск прерван по таймауту». Журналы обоих запусков сохранены в каталоге verification.

Запуск: `./gradlew run --args="samples 10"`. Проверка отмены: `./gradlew run --args="samples 0.000001"`. Первый параметр — каталог, второй — таймаут в секундах.
