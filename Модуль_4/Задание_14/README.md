# Модуль 4. Практическая работа 14

Компас на основе сенсора ориентации

## Цель

Показать магнитный азимут и анимировать стрелку компаса с учётом жизненного цикла Activity.

## Реализация

Использован TYPE_ROTATION_VECTOR. Матрица поворота преобразуется с учётом ориентации дисплея; азимут нормализуется в диапазон от 0 до 360 градусов. ViewModel накапливает минимальную угловую разницу, что исключает полный оборот стрелки при переходе через север. Слушатель подключается на ON_RESUME и освобождается на ON_PAUSE.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t14-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

На эмуляторе отображены круговой диск, двухцветная стрелка и значение азимута. Интерфейс выполнен на тёмном фоне по образцу методички. Предусмотрено сообщение об отсутствии сенсора. Проверка точности физического магнитометра и влияния помех требует реального устройства.

Для проверки точности используйте физический телефон с rotation vector. Поверните устройство и проверьте переход 359° → 0°. На эмуляторе проверены интерфейс и доступные показания, точность не измерялась.
