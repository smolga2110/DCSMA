# Модуль 4. Практическая работа 13

Обновляемый курс валют на основе StateFlow

## Цель

Показать хранение и автоматическое обновление состояния посредством MutableStateFlow.

## Реализация

RateViewModel хранит курс, направление изменения и время обновления. Корутина в viewModelScope каждые пять секунд формирует число в диапазоне 90,5 ± 2,0. Кнопка немедленного обновления вызывает тот же метод. Compose подписывается через collectAsStateWithLifecycle. Цвет и направление стрелки рассчитываются сравнением нового и предыдущего значений.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t13-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Проверены автоматическое и ручное обновления. Экран явно обозначает учебную имитацию. Значение хранится в ViewModel и не задаётся заново при обычной смене конфигурации.

Курс валют имитируется; автоматическое обновление каждые 5 секунд, также доступно ручное.
