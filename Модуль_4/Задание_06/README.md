# Модуль 4. Практическая работа 6

Одноразовый таймер с уведомлением

## Цель

Реализовать одноразовый background-сервис, который ожидает заданное время, уведомляет пользователя и самостоятельно завершается.

## Реализация

TimerService получает длительность через Intent. При повторном запуске предыдущая корутина отменяется. После delay сервис публикует сообщение «Таймер завершён! Время вышло» и вызывает stopSelf. Проверяется ввод целого числа от 1 до 120 секунд. Реализация предназначена для учебного запуска при открытом приложении: обычный background-сервис подчиняется ограничениям Android.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t06-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

При введённом значении 3 таймер завершился и вывел соответствующее сообщение. Проверен запуск из видимой Activity. Для гарантированной продолжительной работы после ухода приложения в фон потребовался бы другой механизм, например AlarmManager или foreground-сервис.

Это обычный background-сервис по условию работы. Оставляйте приложение открытым на время учебного таймера: длительная фоновая работа ограничивается Android. Допустимый ввод: 1–120 секунд.
