# Модуль 4. Практическая работа 5

Счётчик времени с foreground сервисом

## Цель

Создать секундомер, продолжающий работу в foreground-сервисе и отражающий время в постоянном уведомлении.

## Реализация

CounterService запускается через startForegroundService и сразу публикует уведомление. Значение вычисляется по SystemClock.elapsedRealtime, поэтому погрешность не накапливается из-за задержек планировщика. StateFlow передаёт счётчик в Compose. Повторное нажатие запуска не создаёт второй цикл; остановка отменяет область корутин и удаляет foreground-уведомление.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t05-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

На эмуляторе проверены кнопки «Старт» и «Стоп». Во время работы значение увеличивалось. Для Android 13 и выше запрашивается разрешение на уведомления. В манифесте объявлен тип foreground-сервиса specialUse с описанием учебного секундомера.

Разрешите уведомления; нажмите «Старт», сверните приложение, затем вернитесь и нажмите «Стоп».
