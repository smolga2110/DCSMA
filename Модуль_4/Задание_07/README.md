# Модуль 4. Практическая работа 7

Генератор случайных чисел в связанном сервисе

## Цель

Реализовать подключение интерфейса к bound-сервису через Binder и получение обновлений каждую секунду.

## Реализация

RandomService создаёт StateFlow со случайными целыми числами от 0 до 100. Внутренний LocalBinder предоставляет ссылку на сервис. ServiceConnection запускает сбор потока после подключения; при отключении подписка отменяется. DisposableEffect освобождает связь при удалении экрана из композиции. Состояние ожидания предотвращает повторный bind до установления соединения.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t07-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Кнопка «Подключиться» установила связь, после чего экран показал изменяющееся число. Кнопка «Отключиться» остановила получение значений и вернула заглушку. Сервис прекращает цикл при уничтожении.
