# Модуль 4. Практическая работа 11

Ежедневное напоминание через AlarmManager

## Цель

Настроить точное ежедневное напоминание на ближайшие 20 часов и восстановление расписания после перезагрузки.

## Реализация

Время рассчитывается через ZonedDateTime с учётом текущего часового пояса. setExactAndAllowWhileIdle планирует ближайшие 20:00; после срабатывания Receiver назначает следующий запуск. Флаг включения хранится в SharedPreferences. Receiver обрабатывает BOOT_COMPLETED, изменение времени и часового пояса. Используется неизменяемый PendingIntent.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m4t11-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

На эмуляторе проверено включение напоминания и отображение следующего времени. При отсутствии доступа к точным будильникам открываются системные настройки. Выключение отменяет PendingIntent и очищает флаг. Отдельно учитывается разрешение POST_NOTIFICATIONS.

Разрешите уведомления и точные будильники в системном диалоге. Напоминание назначается на ближайшие 20:00 по местному времени; флажок отключает его.
