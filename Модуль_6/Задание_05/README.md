# Модуль 6. Практическая работа 5

Сервер с PostgreSQL в Neon

## Цель

Перенести хранение Nobel Prize API в удалённую PostgreSQL и добавить избранные премии пользователя.

## Реализация

PostgresPrizeRepository подключается к Neon через JDBC с проверкой TLS-сертификата. Таблицы users, prizes, laureates и user_prizes связаны внешними ключами. Первичное заполнение идемпотентно и выполняется транзакционно. Пароли защищены PBKDF2WithHmacSHA256 с солью и 210000 итерациями. Запросы используют параметры PreparedStatement.

## Запуск

Требования: JDK 21 и интернет для первой загрузки зависимостей. Запуск из **этой папки**: `./gradlew run` (Windows: `.\gradlew.bat run`). Сборка: `./gradlew build`.

Swagger UI: `http://localhost:8080/docs`. Учебная учётная запись: `student` / `Student123!`. Тесты: `./gradlew test`. Порт по умолчанию 8080; для одновременного запуска второго сервера задайте `PORT=8081`.

Локальный `.env` уже настроен для Neon. При новом клонировании скопируйте `.env.example` в `.env`, заполните `DATABASE_URL` строкой PostgreSQL и `JWT_SECRET` случайным секретом минимум 32 символа. При старте создаются необходимые таблицы и импортируются 6 премий/11 лауреатов 2023 года.

Файл `.env` содержит приватные настройки и исключён из Git. Не добавляйте его принудительно.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Подтверждено реальное подключение к Neon. Загружены шесть премий и 11 лауреатов из Nobel Prize API. Пройдены 14 HTTP-проверок, включая добавление, повторное добавление, чтение и удаление избранной премии. Повторное добавление не создаёт дубликат благодаря составному первичному ключу.
