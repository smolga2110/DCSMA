# Модуль 6. Практическая работа 7

Монитор сердечного ритма по BLE

## Цель

Реализовать сканирование BLE, подключение к Heart Rate Service и обработку уведомлений Heart Rate Measurement.

## Реализация

BleRepository управляет сканированием, GATT-соединением и состоянием интерфейса. Использованы UUID 0x180D, 0x2A37 и CCC 0x2902. После обнаружения сервиса включаются уведомления характеристики и запись CCC-дескриптора. Парсер учитывает флаг 8- или 16-битного значения и порядок байтов little-endian. Предусмотрены современные и устаревшие callback-методы Android.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m6t07-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Проверены запуск интерфейса и четыре модульных теста: 72 bpm в 8-битном формате, 300 bpm в 16-битном, беззнаковое значение 200 и неполный пакет. Подключение к физическому датчику и поток реальных измерений не проверялись. Для этой проверки в README приведён сценарий с Heart Rate Peripheral.

Разрешите Bluetooth/поиск устройств; на старых Android также геолокацию. Для полного сценария включите BLE-датчик пульса либо второе устройство с периферийным симулятором: сервис 0x180D, характеристика 0x2A37, уведомления CCCD 0x2902. Выполните сканирование, подключение и приём измерений. Эмулятор без периферии не подтверждает физическое соединение. Четыре теста проверяют 8/16-битные пакеты и некорректные данные: `./gradlew :app:testDebugUnitTest`.
