# Модуль 6. Практическая работа 4

Сервер Nobel Prize API с JWT

## Цель

Создать Ktor-сервер с данными в памяти, JWT-авторизацией и защищёнными маршрутами премий.

## Реализация

Сервер разделён на модели, репозитории, сервисы, маршруты и security. POST /auth/login выдаёт JWT на 1800 секунд; подпись HMAC256 проверяется вместе с issuer и audience. Защищены список премий, детализация и список лауреатов. CallLogging регистрирует запросы, StatusPages возвращает контролируемые ошибки. Подготовлена OpenAPI-документация со Swagger UI.

## Запуск

Требования: JDK 21 и интернет для первой загрузки зависимостей. Запуск из **этой папки**: `./gradlew run` (Windows: `.\gradlew.bat run`). Сборка: `./gradlew build`.

Swagger UI: `http://localhost:8080/docs`. Учебная учётная запись: `student` / `Student123!`. Тесты: `./gradlew test`. Порт по умолчанию 8080; для одновременного запуска второго сервера задайте `PORT=8081`.

Данные хранятся в памяти и восстанавливаются из исходного набора после перезапуска. JWT_SECRET можно передать переменной окружения или через `.env`; без настройки ключ генерируется при запуске.

Файл `.env` содержит приватные настройки и исключён из Git. Не добавляйте его принудительно.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Выполнено 14 интеграционных HTTP-проверок: неверный пароль и отсутствие токена дали 401, корректные запросы — 200, неизвестная премия — 404, некорректный год — 400. Набор содержит шесть премий 2023 года. Автоматические тесты проверили авторизацию, операции избранного и хеширование паролей.
