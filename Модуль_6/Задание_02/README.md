# Модуль 6. Практическая работа 2

Нобелевские лауреаты на Ktor Client

## Цель

Создать каталог Нобелевских премий с фильтрами по году и категории и подробными сведениями о лауреатах.

## Реализация

PublicNobelRepository использует Ktor Client. Год проверяется в GetPrizes; названия категорий преобразуются в коды API phy, che, lit, pea, med и eco. JSON-объекты переводятся в доменные Prize и Laureate. Для подробных сведений выполняется отдельный запрос laureate/{id}; учитываются как физические лица, так и организации.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m6t02-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

На эмуляторе загружены премии 2023 года. Карточки содержат категорию, имена и начало мотивации награждения. Детализация показывает полный текст и долю премии, а сведения о стране запрашиваются отдельно. Если фотография отсутствует в API, интерфейс не подставляет вымышленный портрет.

Требуется Nobel Prize API. Проверьте год 2023 и категории, откройте премию и лауреата. API не предоставляет гарантированные фотографии — вместо вымышленных портретов используются текстовые карточки.
