# Модуль 6. Практическая работа 1

Фотокаталог на Retrofit

## Цель

Реализовать сетевой каталог фотографий с разделением ответственности и сохранением выбранного изображения через SAF.

## Реализация

RetrofitPhotoRepository обращается к открытому API Picsum. DTO преобразуются в доменную модель Photo; GetPhotos и PhotoViewModel отделяют сетевой слой от интерфейса. Список показан сеткой в две колонки, Coil загружает превью и полноразмерную фотографию. ActivityResultContracts.CreateDocument предоставляет системный выбор места сохранения.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m6t01-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Каталог получил реальные фотографии с авторами и размерами. При выборе открывается экран детализации. Проверено сохранение фотографии в Downloads через системный диалог SAF; приложение подтвердило успешное завершение. Поток изображения копируется через ContentResolver. Предусмотрены Loading, успешный результат и ошибка с повторным запросом.

Требуется интернет и доступ к Picsum. Откройте фото, нажмите скачивание, выберите Downloads и подтвердите сохранение через системный диалог SAF.
