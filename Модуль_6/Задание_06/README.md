# Модуль 6. Практическая работа 6

Клиент собственного Nobel Prize API

## Цель

Адаптировать клиент каталога премий к собственному серверу с PostgreSQL, сохранив основной интерфейс.

## Реализация

OwnNobelRepository реализует тот же доменный контракт, что и публичный источник. Клиент позволяет указать адрес сервера, авторизоваться и сохранить адрес вместе с JWT в DataStore. Для эмулятора используется 10.0.2.2:8080. Фильтрация выполняется параметрами year и category. Список и детализация используют прежние модели Prize и Laureate.

## Запуск

Требования: JDK 21, Android Studio, Android SDK Platform 35 и Build Tools 35. Откройте **эту папку** как отдельный проект Android Studio, дождитесь синхронизации и запустите конфигурацию app. Минимальная версия устройства — Android 8.0 (API 26). SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`.

Сборка из терминала: `./gradlew :app:assembleDebug` (Windows: `.\gradlew.bat :app:assembleDebug`). Готовый APK лежит в `apk/`; установка: `adb install -r apk/m6t06-debug.apk`.

На Windows при пути с кириллицей используйте `.\verify.ps1` (сборка) или `.\verify.ps1 run` (JVM). Сценарий обходит проблему путей Gradle test worker, размещая сборку в `%TEMP%/MobilePracticeBuild`. Произвольные задачи можно передать аргументами: `.\verify.ps1 TASK`. Путь можно переопределить переменной `PRACTICE_BUILD_DIR` на каталог с ASCII-именем. Для Android вместо TASK укажите `:app:testDebugUnitTest`, если в проекте есть тесты.

## Проверка

Клиент вошёл под учебной учётной записью student и получил премии из собственного Ktor-сервера, подключённого к Neon. На экране показаны категории, имена и мотивации награждения. Проверены связь эмулятора с хостом и совместимость сериализованных моделей.

Сначала запустите сервер задания 5 модуля 6. Адрес для Android Emulator: `http://10.0.2.2:8080`; для телефона — LAN-адрес компьютера. Вход: `student` / `Student123!`. Проверьте фильтры, список и детали. HTTP разрешён для локального учебного сервера.
